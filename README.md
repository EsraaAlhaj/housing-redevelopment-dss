# أولويات تطوير الإسكان — بورسعيد

لوحة Streamlit عربية من صفحة واحدة: قائمة الأولويات، تفاصيل المشروع والمؤشرات، مقارنة مشروعين، وتصدير CSV.

## البيانات المعتمدة

المصدر `data/sample/PortSaid_Scope_2026-10-27.xlsx` هو نسخة دون تعديل من الملف الذي حددته صاحبة المشروع بتاريخ 27 أكتوبر 2026.
تُقرأ `Sheet1` فقط؛ تحتوي على 108 سجلات. نطاق الدراسة 30 سجلًا: 25 متوسط، 1 ردئ، 3 ردئ ومتهالك، و1 متهالك.
يشمل النطاق المشروع 989 (السيد متولى القديم). إجمالي الأعداد المسجلة: 1,289 عمارة و22,160 وحدة، مع فقد أعداد العمارات والوحدات لسجل واحد.

أول تشغيل ينشئ دراسة مستقلة باسم «بورسعيد — نطاق الدراسة المعتمد (30 مشروعًا)». الدراسات القديمة وملفاتها تبقى محفوظة دون دمج أو إعادة كتابة. لا يُستورد جدول Pivot الموجود في Sheet2. عند اختلاف عدد السجلات أو معرفاتها عن المتوقع يظهر خطأ بدل تحميل بيانات غير مطابقة.

## الواجهة

- بحث بالاسم أو المعرّف وفلتر الحي.
- جدول أولوية واحد يضم الدرجة والحالة والقرار المسجل واكتمال البيانات.
- اختيار المشروع يعرض المؤشرات وقيم المصدر وأوزان الدراسة والأوزان المستخدمة فعليًا ومساهمتها بالنقاط.
- مقارنة مشروعين مع إظهار المعرّف في اسم كل مشروع، حتى عند تكرار الاسم.
- تصدير القائمة المصفّاة وتفاصيل المشروع المختار إلى CSV بترميز يدعم العربية.
- إعدادات الإدارة موجودة داخل القسم الجانبي القابل للفتح. لا يوجد تنقل بين لوحتي معلومات، ولا خرائط أو رسوم تكرر الجدول أو نموذج توصية إلزامي.

## المؤشرات والحسابات

الدراسة الحالية تستخدم ستة مؤشرات بوزن إجمالي 100%، بعد استبعاد مؤشر جودة البيئة العمرانية والفراغات العامة من نطاق التقييم الحالي:

| المؤشر | الوزن |
| --- | ---: |
| الحالة الإنشائية والعامة | 35% |
| الأهمية الاستراتيجية | 20% |
| العمر | 15% |
| المخزون والكثافة | 10% |
| التعديلات والإضافات | 10% |
| المرافق والبنية الأساسية | 10% |

تُحوَّل الأهمية الاستراتيجية من قيمة خام من 0 إلى 15 إلى درجة من 0 إلى 100، ثم تُطبّق عليها أوزان الدراسة. عند استعادة الأوزان، يُحدَّث سيناريو الأساس ليطابق المؤشرات الستة.

قواعد التقييم تظل مبدئية في الجوانب التي لا تحسمها البيانات: وجود امتداد لا يثبت عدم اعتماده قانونيًا، واتصال المرافق لا يقيس كفاءتها. بيانات المرافق غير المكتملة لا تُعامل تلقائيًا على أنها انقطاع.

كثافة الوحدات = عدد الوحدات ÷ المساحة بالفدان، ثم تُطبّع نسبيًا بين أقل وأعلى كثافة في مجموعة الدراسة. الدرجة الأعلى تعني كثافة أعلى، لكنها لا تثبت وحدها احتياجًا أكبر لإعادة التطوير؛ يجب تبرير هذا الاتجاه تخطيطيًا قبل استخدام الترتيب لاتخاذ قرارات تنفيذية.

يحافظ المحرك على سياسة البيانات الناقصة: النتيجة المركبة تُحسب من الأوزان المتاحة فقط، مع عرض اكتمال البيانات وتصنيف النتيجة. درجة الأولوية تدعم توجيه المراجعات والمعاينات ولا تصدر قرار إزالة أو ترميم. القرارات الرسمية تُعرض منفصلة عن الدرجة.

## التشغيل والاختبارات

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
python -m pytest tests/ -q
```

تم التحقق من 30 اختبارًا بنجاح، بما فيها تشغيل الصفحة عبر Streamlit AppTest، البحث والتصفية والحالة الفارغة، مقارنة مشروعين لهما الاسم نفسه، استيراد 30 سجلًا، استبعاد المؤشر السابع، الحفاظ على الدراسات القديمة، وتطابق مجموع المساهمات مع الدرجة عند نقص البيانات.

قاعدة SQLite المحلية تُنشأ في `data/housing_dss.sqlite3`. هذا لا يضمن دوام البيانات عبر إعادة بناء حاوية Streamlit Community Cloud؛ لا تُعامل ملفات تشغيل الحاوية كأرشيف دائم.
